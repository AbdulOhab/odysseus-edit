# Odysseus-Edit: notes for coding agents

Odysseus-Edit is a standalone browser image editor extracted from
[Odysseus](https://github.com/odysseus-dev/odysseus) (AGPL-3.0-or-later),
with an optional Python server for AI tools and multi-vendor language models.

## Always do

- **Read [EXPERIENCE.md](EXPERIENCE.md) before changing code.** It records the
  traps already found in this codebase.
- **Append to [WORKLOG.md](WORKLOG.md)** at the end of each work session: date,
  what changed, how it was verified, what is left. Newest entry on top.
- **Add to EXPERIENCE.md** whenever something surprised you or cost time: a
  gotcha, a decision and its reason, a debugging lesson.
- **Commit with git** at each working milestone, with a message that says what
  and why. Never commit `.env` or `config/providers.toml` (both are ignored).
- **AGPL notices:** when you modify a file copied from upstream, add or extend
  its "Modified for Odysseus-Edit (date): ..." line in the header comment and
  keep NOTICE.md accurate.

## Layout

| Path | What |
|---|---|
| `web/` | The app. Plain ES modules, no build step. `index.html` is the start page. |
| `web/js/` | Upstream editor code, mirrored at odysseus `static/js/` paths. `galleryEditor.js` is the 7,900-line orchestrator; `editor/` holds tools. |
| `web/js/ui.js`, `web/js/modalManager.js` | Small shims replacing large upstream modules. |
| `web/app/` | New code: start page (`main.js`), IndexedDB (`db.js`), the host adapter (`host.js`), Quick Edit planner client (`ai-planner.js`), setup help. |
| `web/css/` | `00-tokens.css` and `13-image-editor.css` from upstream; `upstream-pre/post.css` are generated by `tools/sync-upstream-css.sh`. |
| `server/` | Optional FastAPI server (uv project): serves `web/`, image AI endpoints, `/api/ai/*` LLM planner. |
| `config/providers.example.toml` | Multi-vendor provider config (copy to `providers.toml`). |

## Run and test

```bash
# Editor only (no AI): any static server
python3 -m http.server 8000 --directory web

# Editor + AI server
cd server && uv run odysseus-edit        # http://127.0.0.1:7020
cd server && uv run pytest               # server tests
```

The editor talks to its surroundings only through `web/app/host.js`. Do not add
new `fetch('/api/...')` calls inside `web/js/` for storage or files; extend the
host instead.
